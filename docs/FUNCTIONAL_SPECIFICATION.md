# Functional Specifications

## 1. Authentication & Role Separation
Three role tiers:
1. ROLE_ADMIN: User management, course approvals, system health, audit logs.
2. ROLE_TEACHER: Class management, lesson authoring, geometry creation, test submission for approval.
3. ROLE_STUDENT: Course viewing, 3D geometry exploration, assignment submission, AI tutoring.

## 2. Geometry Engine Workflows
- Primitives: Points, Lines, Planes, Angles, Distances.
- Solids: Pyramids, Prisms, Cuboids, Cones, Cylinders, Spheres.
- Real-time parameter recalculation: Volume, Surface Area, Heights, Intersections.
