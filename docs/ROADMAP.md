# Development Roadmap

- [x] **Phase 0 – Foundation:** Environment survey, Monorepo structure, Docker Compose (PostgreSQL, pgvector, MinIO, Prometheus, Grafana, Loki), Geometry Core, Spring Boot API, React Web app, Full documentation.
- [ ] **Phase 1 – Core Platform:** RBAC enforcement, User profile management, Class rosters, Course modules.
- [ ] **Phase 2 – Geometry Engine:** Complete 2D/3D solver suite, dynamic drag-and-drop constraints, cross-section plane slider.
- [ ] **Phase 3 – AI Agent:** OCR ingestion, LLM tool integration, theorem citation, step-by-step verification.
- [ ] **Phase 4 – Learning Platform:** Assignments, online examinations, teacher grading, student progress analytics.
- [ ] **Phase 5 – Observability & Hardening:** Production WAF deployment, k6 load testing, distributed tracing with OpenTelemetry.
- [ ] **Phase 6 – Production Deployment:** High-availability cluster deployment, disaster recovery drill, final acceptance.
