# UI/UX & Design Guidelines

1. **Aesthetic Direction:** Premium EdTech, modern, clean, uncluttered.
2. **Color Palette:** Slate-950 dark background, Brand blue (#307eff), Emerald accents for verified states, Amber for alerts.
3. **Typography:** Plus Jakarta Sans for UI readability; JetBrains Mono for coordinates and calculations.
4. **3D Canvas:** Integrated seamlessly into cards with rounded borders, responsive canvas resize, and high-performance WebGL rendering.
