# Skill: premium-ui-ux

## Description
Ensures CH EdTech maintains a world-class, premium, clutter-free educational interface.

## Scope & Applicability
- Layouts, color palettes, typography, spacing, and micro-interactions.
- Public landing, Admin, Teacher, and Student portals.

## Rules & Principles
1. Clean UI with purposeful negative space, high contrast readability, and consistent typographic hierarchy.
2. No unnecessary neon glow, excessive glassmorphism, or distracting decorative animations.
3. Support both high-fidelity Dark and Light themes with fluid transitions.
4. 3D canvas must integrate smoothly without blocking page scroll or degrading UI responsiveness.

## Checklist
- [ ] Consistent 4px/8px spacing grid.
- [ ] WCAG AA color contrast compliance.
- [ ] Fluid responsive layouts for desktop, tablet, and mobile.
